安裝 德化廟務

iPhone

下載安裝檔
  1. 按上面的按鈕，跳出提示時按「允許」
  2. 打開「設定」，最上面會出現「已下載描述檔」，點進去
  3. 右上角按「安裝」，輸入手機密碼，再按兩次「安裝」
  4. 回到主畫面，就會看到「德化廟務」
請用 Safari 開啟這個頁面。安裝時顯示「未簽署」是正常的，這個描述檔只會在主畫面加一個圖示。

Android

下載 App
  1. 按上面的按鈕下載
  2. 下載完成後點開檔案
  3. 如果出現「不允許安裝不明來源」，按「設定」→ 開啟「允許此來源」→ 返回
  4. 按「安裝」，完成後就能在主畫面看到「德化廟務」
出現 Play 安全防護提示時，選「仍要安裝」。
